# Prompts de Ejecución - Sistema de Gestión Hotelera

## Prompt 1: Crear estructura base del proyecto

> Crea un proyecto fullstack con Next.js para el frontend y Node.js con Express para el backend, incluyendo conexión a una base de datos PostgreSQL.

## Prompt 2: Sistema de autenticación

> Implementa un sistema de autenticación con registro e inicio de sesión usando JWT, incluyendo roles: SuperAdmin, Recepción y Cliente.

## Prompt 3: CRUD de habitaciones

> Crea un CRUD completo de habitaciones con los campos: número, tipo, estado y precio por noche.

## Prompt 4: Sistema de reservas

> Desarrolla un sistema para crear reservas que permita seleccionar fechas de entrada y salida, asignar una habitación disponible y asociar un cliente.

## Prompt 5: Dashboard

> Crea un dashboard moderno que muestre habitaciones disponibles, reservas activas y estadísticas del hotel.

## Prompt 6: Buscador

> Implementa un buscador que permita encontrar clientes por nombre y mostrar sus reservas.

## Prompt 7: Diseño UI

> Aplica un diseño moderno y profesional usando Tailwind CSS, con un login elegante y un dashboard limpio.

## Prompt 8: Control de roles

> Implementa control de acceso donde:
> - SuperAdmin puede gestionar todo
> - Recepción gestiona reservas
> - Cliente solo ve sus reservas
